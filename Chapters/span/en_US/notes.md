# Span — Notes

## Summary
Explains span geometrically (one independent vector spans a line, two independent vectors a plane, three independent vectors in ℝ³ span ℝ³) and formally, then tests independence for a three-vector example and a short determining-span exercise. Opens with a city-walking picture of lines, planes, and space.

## Changes in this pass
- Fixed the general claim that any list of dependent vectors spans a line. A list spans a line only when every vector lies on one line through the origin. A dependent list can still span a plane.
- Replaced the summary sentence "3 dependent vectors span R³" with the correct rule: the span's size depends on how many independent vectors the list contains.
- Made t = [0, 2, 4] consistent in the dependence check. The relation for s and t is now a₂ = (5/2)a₁, and a₁ = 2, a₂ = 5 is the example.
- Fixed the missing coefficient in −6a₁ − 10a₂ = 0.
- Removed stray commas inside vector brackets.
- Stated that the third exercise set spans ℝ³ because the determinant of the matrix is −9, not 0.
- Added an unworked exercise on three vectors in ℝ³ (determinant 2, so the span is ℝ³).
- Fixed "we say the the span" and added a city-walking picture of lines, planes, and space.

## Strengths
- The span exercise answers are correct: the first pair is dependent (a line), the second pair spans a plane, and the third set spans ℝ³.
- The example's conclusion (r and s independent, r and t independent, s and t dependent, so the span is a plane) is correct.
