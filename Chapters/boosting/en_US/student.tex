\chapter{Boosting}

\section{Learning from Mistakes}\index{boosting}
\newterm{Boosting} combines many weak learners into one strong learner. A weak learner is only a little better than guessing.
Each new learner is trained to focus on the examples the earlier learners got wrong. Think of studying for a test. After each practice test, you spend more time on the problems you missed. Boosting mainly reduces bias.

\section{AdaBoost}\index{AdaBoost}
\newterm{AdaBoost} (adaptive boosting) works with labels $y_i \in \{-1, +1\}$. It keeps a weight $w_i$ for each training point.
\begin{enumerate}
\item Start with equal weights, $w_i = \frac{1}{n}$.
\item For $t = 1, \ldots, T$: train a weak learner $h_t$ on the weighted data, compute its weighted error
$\varepsilon_t = \sum_{i:\, h_t(x_i) \ne y_i} w_i$, and set
$$\alpha_t = \frac{1}{2}\ln\frac{1 - \varepsilon_t}{\varepsilon_t}$$
\item Increase the weights of the misclassified points and decrease the others:
$w_i \leftarrow w_i e^{-\alpha_t y_i h_t(x_i)}$, then normalize so the weights sum to 1.
\end{enumerate}
The final classifier is the sign of the weighted vote, $H(x) = \operatorname{sign}\left(\sum_t \alpha_t h_t(x)\right)$.

\subsection{A Worked Round}
Four points have weights $\frac{1}{4}$ each. A weak learner misclassifies only the fourth point, so $\varepsilon_1 = \frac{1}{4}$ and
$$\alpha_1 = \frac{1}{2}\ln\frac{3/4}{1/4} = \frac{1}{2}\ln 3 \approx 0.549$$
The three correct points have weight $\frac{1}{4} e^{-0.549} \approx 0.144$ before normalizing, and the misclassified point has weight
$\frac{1}{4} e^{0.549} \approx 0.433$. Normalizing (the total is $0.144 \cdot 3 + 0.433 = 0.866$), the misclassified point now has weight
$0.5$, and each correct point has weight $\frac{1}{6} \approx 0.167$. The next learner is forced to focus on the point that was missed.

\section{Gradient Boosting}\index{gradient boosted trees}
\newterm{Gradient boosting} generalizes this idea to any differentiable loss. Each new tree is fit to the negative gradient of the loss at the
current predictions. For squared-error loss, this gradient is just the residual, so each tree is fit to the errors of the ensemble so far.

\section{Cautions}
Boosting can overfit if the number of rounds is too large. The validation set is used to choose the number of rounds, and the
learning rate is usually made small to slow the fit.

\begin{Exercise}[label=bst1, title=Compute alpha]
A weak learner has weighted error $\varepsilon = 0.1$. What is $\alpha$?
\end{Exercise}
\begin{Answer}[ref=bst1]
$\alpha = \frac{1}{2}\ln\frac{0.9}{0.1} = \frac{1}{2}\ln 9 \approx 1.099$.
\end{Answer}

\begin{Exercise}[label=bst2, title=Which points gain weight?]
After a round of AdaBoost, which points have their weights increased?
\end{Exercise}
\begin{Answer}[ref=bst2]
The points that were misclassified by $h_t$. Since $y_i h_t(x_i) = -1$ for those points, $e^{-\alpha_t y_i h_t(x_i)} = e^{\alpha_t} > 1$.
\end{Answer}
