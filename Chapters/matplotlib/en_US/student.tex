\chapter{Making Plots with matplotlib}

A table of a thousand numbers tells you almost nothing at a glance; a
picture of them can tell you everything. You have graphed functions in
algebra class by plotting points on a grid. Matplotlib, the most widely used
Python plotting library, does the same job for you: it draws the grid, the
points, the lines, and the labels. We will use it throughout the series to
visualize data, check formulas, and watch simulations unfold.\index{matplotlib}\index{creating charts in python|see{matplotlib}}

Matplotlib is a \emph{library}, so we start with what that means.

\section{Libraries}\index{libraries}
A \newterm{library} is a collection of pre-written code that adds features to
Python, so you do not have to write everything from scratch. Python comes with
many built-in libraries for common tasks such as math, reading files, and
working with dates, and thousands more can be installed. Before you write
something big, check whether someone has already written it: there is a free,
open-source Python library for almost everything.

To use a library, you must first import it. The simplest way is the
\mintinline{python}{import} keyword:

\begin{minted}{python}
import math
print(math.sqrt(16))
\end{minted}

The \mintinline{python}{math} library provides functions such as square roots.
Notice that you write the library's name, a dot, and then the function.

You can also import a specific value or function, and then use it without the
library's name:

\begin{minted}{python}
from math import pi
print(pi)
\end{minted}

\section{Installing and Importing Matplotlib}
Matplotlib does not come with Python. If you are working on your own computer,
install it from the command line:
\begin{minted}{bash}
pip install matplotlib
\end{minted}

In most programs, you will import its plotting interface, \texttt{pyplot}, and
give it the short name \texttt{plt}:
\begin{minted}{python}
import matplotlib.pyplot as plt
\end{minted}

\section{A Simple Line Plot}\index{line plot}
A line plot is ideal for showing how a value changes over time or across an
ordered variable. Create a file called \filename{line.py}:

\begin{minted}{python}
import matplotlib.pyplot as plt

# two lists containing values
x = [0, 1, 2, 3, 4, 5]
y = [0, 1, 4, 9, 16, 25]

plt.plot(x, y)                 # draw y versus x
plt.title("A Simple Line Plot")
plt.xlabel("x")
plt.ylabel("y = x^2")
plt.show()                     # open a window with the plot
\end{minted}

Here, \texttt{x} and \texttt{y} are the coordinates of the points, and
\texttt{plt.plot} connects them with lines. The title and axis labels tell a
reader what they are looking at; a plot without them is just a squiggle.
Running \mintinline{bash}|python3 line.py| opens an interactive window with
the plot:

\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth]{line.png}
    \caption{The output of \filename{line.py}.}
    \label{fig:line}
\end{figure}

\begin{Exercise}[title={A Line Plot}, label=pyl_line]
Write a program that plots $y = 2x$ for $x = 0, 1, 2, 3, 4$. Add a title and axis labels.
\end{Exercise}
\begin{Answer}[ref=pyl_line]
\begin{minted}{python}
import matplotlib.pyplot as plt

x = [0, 1, 2, 3, 4]
y = [2 * v for v in x]

plt.plot(x, y)
plt.title("y = 2x")
plt.xlabel("x")
plt.ylabel("y")
plt.show()
\end{minted}
The plot is a straight line through $(0, 0)$ and $(4, 8)$.
\end{Answer}

\section{Bar Plots}\index{bar plot}
A bar plot compares amounts across categories:

\begin{minted}{python}
import matplotlib.pyplot as plt

labels = ["A", "B", "C", "D", "E"]
values = [5, 7, 9, 11, 13]

plt.bar(labels, values)
plt.show()
\end{minted}

Here, \texttt{labels} are the categories, and \texttt{values} are the heights of
their bars.

\section{Several Lines on One Plot}

Call \pyfunction{plt.plot} more than once before \pyfunction{plt.show}, and
the lines share the same axes. Give each a \texttt{label}, and
\pyfunction{plt.legend} draws a key. The \texttt{marker} and
\texttt{linestyle} options make the lines easy to tell apart, even in
black and white, and \pyfunction{plt.grid} adds grid lines:

\begin{minted}{python}
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
plt.plot(x, [1, 4, 9, 16, 25], marker="o", label="x squared")
plt.plot(x, [1, 8, 27, 64, 125], marker="s", linestyle="--", label="x cubed")
plt.xlabel("x")
plt.ylabel("y")
plt.title("Squares and Cubes")
plt.grid(True)
plt.legend()
plt.show()
\end{minted}

\begin{figure}[H]
\centering
\includegraphics[width=0.6\textwidth]{mpl_lines.png}
\caption{Two lines with markers and a legend.}
\label{fig:mpl_lines}
\end{figure}

To save a plot as an image file, call \pyfunction{plt.savefig("myplot.png")}
\emph{before} \pyfunction{plt.show}; after the window closes, the figure is
gone.

\section{Scatter Plots}\index{scatter plot}

A \newterm{scatter plot} draws one dot per data point, with no connecting
lines. It is the right tool for asking how two variables relate. Here are six
students' study times and test scores:

hours = [1, 2, 3, 4, 5, 6]

\subsection{Plotting Data from a File}
Real data usually lives in a file. Your digital resources include
\filename{dataset.csv}, a \newterm{CSV} (comma-separated values) file with 50
rows. Each row has a \texttt{Category} (A, B, C, or D), an \texttt{X\_values}
column, and a \texttt{Y\_values} column. The line
\mintinline{python}{with open("dataset.csv") as f:} opens the file and calls it
\texttt{f}; when the indented block ends, Python closes the file for you.
Python's built-in \texttt{csv} library then reads it for us. \texttt{csv.DictReader} turns each row into a
dictionary whose keys are the column names. Because the file stores text,
we convert the numbers with \texttt{float}. This program draws each category
in its own color:

\begin{minted}{python}
import csv
import matplotlib.pyplot as plt

# Read the file into a list of dictionaries, one per row
with open("dataset.csv") as f:
    rows = list(csv.DictReader(f))

for category in ["A", "B", "C", "D"]:
    xs = [float(r["X_values"]) for r in rows if r["Category"] == category]
    ys = [float(r["Y_values"]) for r in rows if r["Category"] == category]
    plt.scatter(xs, ys, label=category)

plt.xlabel("X value")
plt.ylabel("Y value")
plt.title("Points by Category")
plt.legend()
plt.show()
\end{minted}

\begin{figure}[H]
\centering
\includegraphics[width=0.6\textwidth]{mpl_scatter.png}
\caption{The points of \filename{dataset.csv}, colored by category.}
\label{fig:mpl_scatter}
\end{figure}

The dots are spread all over, with no clear upward or downward trend: in
this data set, knowing $X$ does not help you predict $Y$.

\section{Histograms}\index{histogram}

A \newterm{histogram} shows how one set of numbers is distributed. It
divides the range into equal \newterm{bins} and draws a bar for how many
values land in each:

\begin{minted}{python}
import matplotlib.pyplot as plt

# for example, maybe these are quiz scores
data = [4, 5, 5, 6, 7, 7, 7, 8, 8, 9, 10, 10, 10, 11, 12]

plt.hist(data, bins=5)
plt.title("Histogram of Values")
plt.xlabel("value")
plt.ylabel("frequency")
plt.show()
\end{minted}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth]{histogram.png}
    \caption{A histogram of 15 values in 5 bins.}
    \label{fig:histogram}
\end{figure}

\textbf{Worked example: reading a histogram.} The histogram above splits the
15 values into 5 bins of equal width, from 4 to 12, so each bin is
$\frac{12 - 4}{5} = 1.6$ units wide. The counts are $3, 4, 2, 4, 2$, which add
up to $15$. Matplotlib chooses the bin edges for you. The tallest bars show
where the values cluster.

Here is the distribution of the \texttt{Y\_values} column of
\filename{dataset.csv}:

\begin{minted}{python}
import csv
import matplotlib.pyplot as plt

with open("dataset.csv") as f:
    ys = [float(r["Y_values"]) for r in csv.DictReader(f)]

plt.hist(ys, bins=10, edgecolor="black")
plt.xlabel("Y value")
plt.ylabel("Number of points")
plt.title("Distribution of Y Values")
plt.show()
\end{minted}

\begin{figure}[H]
\centering
\includegraphics[width=0.6\textwidth]{mpl_hist.png}
\caption{Most $Y$ values fall between 40 and 65, with one outlier above 80.}
\label{fig:mpl_hist}
\end{figure}

Try changing \texttt{bins=10} to 5 or 25. Too few bins hide the shape; too
many make it jagged.

\begin{Exercise}[title={Averages by Category}, label=mpl3]
Using \filename{dataset.csv}, make a bar plot of the average
\texttt{Y\_values} for each category. Which category has the highest
average?
\end{Exercise}
\begin{Answer}[ref=mpl3]
\begin{minted}{python}
import csv
import matplotlib.pyplot as plt

with open("dataset.csv") as f:
    rows = list(csv.DictReader(f))

categories = ["A", "B", "C", "D"]
averages = []
for category in categories:
    ys = [float(r["Y_values"]) for r in rows if r["Category"] == category]
    averages.append(sum(ys) / len(ys))
    print(category, round(averages[-1], 1))

plt.bar(categories, averages)
plt.xlabel("Category")
plt.ylabel("Average Y value")
plt.title("Average Y Value by Category")
plt.show()
\end{minted}
The averages are about A: 49.5, B: 48.4, C: 49.1, and D: 55.5. Category D
is highest.
\end{Answer}

\section{The Object-Oriented Approach}
Matplotlib has two styles:
\begin{itemize}
  \item \textbf{State-based} (\texttt{plt.plot}, \texttt{plt.title}, \dots): quick and convenient. Everything so far has used this style.
  \item \textbf{Object-oriented} (creating a \texttt{Figure} and its \texttt{Axes}): more explicit, and easier to manage when a figure has several plots.
\end{itemize}

For layouts with several plots, prefer the object-oriented approach:

\begin{minted}{python}
import matplotlib.pyplot as plt

x = [0, 1, 2, 3, 4, 5]
y1 = [0, 1, 4, 9, 16, 25]
y2 = [0, 1, 8, 27, 64, 125]

# one figure with two plots side by side; axes is a list of them
fig, axes = plt.subplots(nrows=1, ncols=2)

axes[0].plot(x, y1)
axes[0].set_title("x^2")
axes[0].set_xlabel("x")
axes[0].set_ylabel("value")

axes[1].plot(x, y2)
axes[1].set_title("x^3")
axes[1].set_xlabel("x")
axes[1].set_ylabel("value")

fig.suptitle("Two Subplots")
fig.tight_layout()
plt.show()
\end{minted}

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{lineOOP.png}
    \caption{The two plots, generated side by side.}
    \label{fig:lineOOP}
\end{figure}
