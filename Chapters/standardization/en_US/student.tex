\chapter{Standardizing Data}

\section{The Standard Score}\index{standardization}
\newterm{Standardization} rescales a variable so that its mean is 0 and its standard deviation is 1.
For a variable $X$ with mean $\mu$ and standard deviation $\sigma$,
$$Z = \frac{X - \mu}{\sigma}$$
Each value $Z$ is the number of standard deviations the original value lies above or below the mean.
This is the same $z$-score used in the chapter on describing data.

\section{A Worked Example}
Take the values $2, 4, 6, 8$. The mean is $\mu = 5$. Using the population standard deviation,
$\sigma = \sqrt{\frac{(-3)^2 + (-1)^2 + 1^2 + 3^2}{4}} = \sqrt{5} \approx 2.236$. The standardized values are
$$\frac{2 - 5}{2.236} \approx -1.342, \quad \frac{4 - 5}{2.236} \approx -0.447, \quad
\frac{6 - 5}{2.236} \approx 0.447, \quad \frac{8 - 5}{2.236} \approx 1.342$$
The new values have mean 0 and standard deviation 1.

\section{Why Standardize?}
Standardization matters for methods that combine several features. In those methods, a feature with
large numbers can dominate the calculation simply because of its units. Standardization puts the features on
the same scale.
\begin{itemize}
\item \textbf{Gradient descent} converges faster when all features have similar scales, because the cost
function is less stretched.
\item \textbf{Distance-based methods}, such as k-nearest neighbors, depend on the scale of each feature.
\item \textbf{Regularized regression} and \textbf{principal components} are sensitive to scale, so their
results change with the units of the inputs.
\item \textbf{Coefficients} become easier to compare. In a standardized regression, each coefficient is the change in
the response, in standard deviations, for a one-standard-deviation increase in that predictor.
\end{itemize}

\section{Two Cautions}
Standardization does not make variables have equal variance in any deep sense; it only sets the variance to 1.
Tree-based models, such as decision trees, are not affected by monotone rescaling of a feature, so they do not need
standardization. Compute $\mu$ and $\sigma$ from the training data only, and then apply the same values to the
validation and test data. Otherwise, information from the test set leaks into training.

\begin{Exercise}[label=std1, title=Standardize a value]
A data set has mean 50 and standard deviation 10. What is the standardized value of 65?
\end{Exercise}
\begin{Answer}[ref=std1]
$Z = \frac{65 - 50}{10} = 1.5$.
\end{Answer}

\begin{Exercise}[label=std2, title=Leakage]
A student computes $\mu$ and $\sigma$ from all the data, then splits it into training and test sets. What is the problem?
\end{Exercise}
\begin{Answer}[ref=std2]
The test data helped determine the scaling, so information from the test set has leaked into training.
The fix is to compute $\mu$ and $\sigma$ from the training set only.
\end{Answer}
