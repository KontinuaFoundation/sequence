\chapter{Multiple Logistic Regression}

Whether you get into a college depends on more than your GPA. Test scores,
activities, and essays all matter at the same time. Real yes-or-no outcomes
usually have several causes, so we need a logistic model that can use several
predictors at once.

\section{More Than One Predictor}\index{logistic regression!multiple}
\newterm{Multiple logistic regression} extends simple logistic regression to several predictors
$x_1, \ldots, x_p$. The model for the log odds is
$$\ln\left(\frac{P(Y = 1)}{1 - P(Y = 1)}\right) = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p$$
Equivalently,
$$P(Y = 1 \mid x) = \frac{e^{\beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p}}{1 + e^{\beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p}}$$

\section{Interpreting the Coefficients}
Each coefficient describes one predictor while the others are held constant. A one-unit increase in $x_i$
multiplies the odds of $Y = 1$ by $e^{\beta_i}$.

\section{A Worked Example}
Suppose a student's chance of passing an exam is modeled with hours studied $x_1$ and prior course
completion $x_2$ (1 if yes, 0 if no), with $\beta_0 = -3$, $\beta_1 = 0.5$, and $\beta_2 = 1$. The linear predictor is
$$\eta = -3 + 0.5 x_1 + x_2$$
For a student who studies 4 hours and completed the prior course, $\eta = -3 + 2 + 1 = 0$, so
$P(\text{pass}) = \frac{1}{1 + e^0} = 0.5$. For a student who studies 2 hours and did not complete the
prior course, $\eta = -2$, so $P(\text{pass}) = \frac{1}{1 + e^{2}} \approx 0.119$. The odds ratio for
hours studied is $e^{0.5} \approx 1.649$.

\section{The Divide by 4 Rule}
The coefficients can be used to estimate effects quickly. The logistic curve has slope $\frac{1}{4}$ at its midpoint,
where $P = 0.5$. So near $P = 0.5$, a one-unit increase in $x_i$ changes the probability by about $\frac{\beta_i}{4}$.
This is an approximation. It is most accurate when the probability is near 0.5 and the coefficient is small.

\section{Checking the Model}
Compare models with and without a predictor using a likelihood ratio test or an information criterion. Check
that predictors are not strongly correlated with each other, since correlated predictors make the individual
coefficients unstable.

\begin{Exercise}[label=mlog1, title=Compute a probability]
Using the model above, find $P(\text{pass})$ for a student who studies 6 hours and did not complete the prior course.
\end{Exercise}
\begin{Answer}[ref=mlog1]
$\eta = -3 + 0.5(6) + 0 = 0$, so $P = 0.5$.
\end{Answer}

\begin{Exercise}[label=mlog2, title=Odds ratio]
In the same model, by what factor do the odds of passing change when a student completes the prior course, holding hours fixed?
\end{Exercise}
\begin{Answer}[ref=mlog2]
The odds are multiplied by $e^{\beta_2} = e^{1} \approx 2.718$.
\end{Answer}

\begin{Exercise}[label=mlog3, title=Divide by 4]
In the worked example, the first student (4 hours, completed the prior course)
has $P(\text{pass}) = 0.5$. Use the divide-by-4 rule to estimate their
probability of passing if they study one more hour. Then compute it exactly.
\end{Exercise}
\begin{Answer}[ref=mlog3]
The rule says the probability rises by about $\frac{0.5}{4} = 0.125$, to about $0.625$.
Exactly, $\eta = 0.5$ and $P = \frac{1}{1 + e^{-0.5}} \approx 0.622$. The rule is
very close because the student starts at $P = 0.5$.
\end{Answer}
