What ticket price brings in the most money for the school dance? What
shape of soda can uses the least aluminum? How should you fence a garden
to enclose the most area? Each of these asks for the \emph{best} value of
something, and finding it is called \newterm{optimization}\index{optimization}.

The quantity you are trying to make as large or as small as possible is
the \index{objective function}\newterm{objective function}. The key idea
is one you met in the last volume: at a smooth peak or valley, the
derivative is zero. So we look for the \index{critical point}critical
points, where $f'(x) = 0$.

At a critical point where the derivative is zero, the graph of the
function has a horizontal tangent line. At such a point, the function
may be reaching a peak or a valley (Figure~\ref{fig:duck-hiker}).

$y = x^3$, the graph flattens out for a moment and keeps going: a
\index{inflection point}horizontal point of inflection

\section{Extrema}



There are two types of extrema: relative extrema and absolute extrema.

A relative maximum or minimum occurs when the function reaches a peak
or valley compared to nearby values. This does not guarantee that the
value is the highest or lowest value of the function overall.\index{relative extrema} \index{relative maximum} \index{relative minimum}

An absolute maximum or minimum is the greatest or least value that the
function takes on a given interval. \index{absolute extrema} \index{absolute maximum} \index{absolute minimum}

An absolute maximum or minimum can occur either at a critical point or
at an endpoint of the interval.

For this reason, when solving \index{closed interval method}optimization problems on a restricted
domain, it is important to test both critical points and endpoints (Figure~\ref{fig:closed-interval-extrema}).

\section{The Second Derivative Test}

Once a critical point has been found, we often want to determine whether
it corresponds to a maximum or a minimum. One method for doing this is
the Second Derivative Test. \index{second derivative test}

If a function has a critical point at $x = c$, then:
\begin{itemize}
\item if the second derivative is positive at $x = c$, the function is
concave up and the point is a relative minimum;
\item if the second derivative is negative at $x = c$, the function is
concave down and the point is a relative maximum;
\item if the second derivative is zero at $x = c$, the test is
inconclusive.
\end{itemize}

If the second derivative is always positive or always negative on an
interval, then any critical point in that interval must be an absolute
minimum or absolute maximum, respectively.

\section{A Strategy for Optimization Problems}\index{optimization!general strategy}

The stories change, but the steps do not:

\begin{enumerate}
\item Identify the quantity to be optimized.
\item Write an equation for the objective function. \index{optimization!word problems}In word problems, this is usually the hard part, and a sketch helps.
\item Use the given constraints to rewrite the function using one
variable.
\item Determine the appropriate domain.
\item Find the derivative of the function.
\item Find critical points by setting the derivative equal to zero.
\item Check that each one is a maximum or minimum (second derivative test), and check the endpoints of the domain.
\item Interpret the result in the context of the problem.
\end{enumerate}

When solving optimization problems, some common mistakes include
forgetting to define variables, not using the constraints of the
problem appropriately, misinterpreting or failing to interpret the
final answer, and giving answers without units. Ask yourself whether
the answer makes sense: a fence with negative length means something went
wrong.

\subsection{Example}

Consider the function
\[
f(x) = x^2 - 4x + 1.
\]

We want to find the maximum or minimum value of this function.

First, take the derivative of the function:
\[
f'(x) = 2x - 4.
\]

Next, set the derivative equal to zero to find the critical point:
\[
2x - 4 = 0.
\]

Solving for $x$ gives
\[
x = 2.
\]

Now determine whether this critical point corresponds to a maximum or a
minimum by using the second derivative.

The second derivative is
\[
f''(x) = 2.
\]

Because the second derivative is positive, the function is concave up,
and the critical point corresponds to a minimum.

To find the minimum value of the function, substitute $x = 2$ back into
the original function:
\[
f(2) = 2^2 - 4(2) + 1 = -3.
\]

Therefore, the function has a minimum value of $-3$ at $x = 2$.

\begin{Answer}[ref=optimization1]

\]

Set the derivative equal to zero to find the critical point:
\[
2x - 6 = 0.
\]

Solving this equation gives
\[
x = 3.
\]

Next, take the second derivative:
\[
f''(x) = 2.
\]

Since the second derivative is positive, the function is concave up, and
the critical point corresponds to a minimum.

Finally, substitute $x = 3$ back into the original function:
\[
f(3) = 3^2 - 6(3) + 5 = -4.
\]

Therefore, the function has a minimum value of $-4$ at $x = 3$.
\end{Answer}

\subsection*{Example}

\index{optimization!cost minimization}The cost, in dollars, of producing $x$ units of a product is given by the
function
\[
C(x) = 2x^2 - 24x + 100.
\]

Find the number of units that should be produced in order to minimize
the cost, and determine the minimum cost.

\medskip

To minimize the cost, take the derivative of the cost function:
\[
C'(x) = 4x - 24.
\]

Set the derivative equal to zero to find the critical point:
\[
4x - 24 = 0.
\]

Solving for $x$ gives
\[
x = 6.
\]

Next, take the second derivative:
\[
C''(x) = 4.
\]

Since the second derivative is positive, the cost function is concave
up, and the critical point corresponds to a minimum.

Substitute $x = 6$ back into the original cost function:
\[
C(6) = 2(6)^2 - 24(6) + 100 = 28.
\]

Therefore, the cost is minimized when 6 units are produced, and the
minimum cost is \$28 (Figure~\ref{fig:cost-minimum}).

\begin{Exercise}[label = optimization2]
\index{optimization!enclosure problem}A rectangular enclosure is to be built using 60 units of fencing. Three
sides of the enclosure require fencing, while the fourth side is along
a wall and does not require fencing.

Let $x$ represent the length of the side parallel to the wall and $y$
represent the width of the enclosure (Figure~\ref{fig:fence-enclosure}).

Find the dimensions of the enclosure that maximize the enclosed area.
\end{Exercise}

\begin{Answer}[ref=optimization2]

Because only three sides require fencing, the total amount of fencing is
given by
\[
x + 2y = 60.
\]

Solving this equation for $x$ gives
\[
x = 60 - 2y.
\]

The area of the enclosure is
\[
A = xy.
\]

Substituting for $x$ yields
\[
A(y) = y(60 - 2y) = 60y - 2y^2.
\]

Take the derivative:
\[
A'(y) = 60 - 4y.
\]

Set the derivative equal to zero:
\[
60 - 4y = 0.
\]

Solving for $y$ gives
\[
y = 15.
\]

The second derivative is
\[
A''(y) = -4.
\]

Since the second derivative is negative, this critical point corresponds
to a maximum area.

Substituting $y = 15$ into the constraint gives
\[
x = 60 - 2(15) = 30.
\]

Therefore, the enclosure has dimensions 30 units by 15 units, and its maximum area is $30 \times 15 = 450$ square units.
\end{Answer}

\subsection*{Example: The Soda Can}
\index{optimization!soda can}
A soda can holds 355 cm$^3$. What radius and height use the least
aluminum?

\textbf{Solution:} We want to minimize the surface area of a cylinder
with radius $r$ and height $h$: two circular ends plus the side.
$$A = 2\pi r^2 + 2\pi r h$$
The constraint is the volume: $\pi r^2 h = 355$, so $h = \frac{355}{\pi
r^2}$. Substituting,
$$A(r) = 2\pi r^2 + 2\pi r \cdot \frac{355}{\pi r^2} = 2\pi r^2 + \frac{710}{r}$$
The domain is $r > 0$. Differentiate and set equal to zero:
$$A'(r) = 4\pi r - \frac{710}{r^2} = 0 \quad\Rightarrow\quad r^3 = \frac{710}{4\pi} \quad\Rightarrow\quad r \approx 3.84 \text{ cm}$$
$A''(r) = 4\pi + \frac{1420}{r^3} > 0$, so this is a minimum. The height
is $h = \frac{355}{\pi (3.84)^2} \approx 7.67$ cm, exactly twice the radius:
the best can is as tall as it is wide.

Real soda cans are about 6.6 cm wide and 12 cm tall. They use about 2\%
more aluminum than the ideal, but they are easier to hold, and their
thick ends are cheaper to make small.

\begin{Exercise}[title={The Open Box}, label=optimization_box]
\index{optimization!open box}
You have a 30 cm by 30 cm square of cardboard. You cut a square of side $x$
from each corner and fold up the sides to make an open box. What value of
$x$ gives the largest volume? What is that volume?
\end{Exercise}
\begin{Answer}[ref=optimization_box]
The base is $(30 - 2x)$ by $(30 - 2x)$ and the height is $x$, so
$V(x) = x(30 - 2x)^2$ with $0 < x < 15$. By the product and chain rules,
$$V'(x) = (30 - 2x)^2 + x \cdot 2(30 - 2x)(-2) = (30 - 2x)(30 - 6x)$$
$V' = 0$ at $x = 15$ (an endpoint, where the volume is 0) and $x = 5$. So
cut 5 cm squares: $V(5) = 5 \cdot 20^2 = 2{,}000$ cm$^3$.
\end{Answer}

\begin{Exercise}[title={The School Dance}, label=optimization_dance]
\index{optimization!revenue}
At \$10 a ticket, 300 students come to the school dance. For every \$1 the
price goes up, 20 fewer students come. What ticket price brings in the
most money? How many students come, and what is the revenue?
\end{Exercise}
\begin{Answer}[ref=optimization_dance]
Let $p$ be the price increase in dollars. Revenue is price times attendance:
$$R(p) = (10 + p)(300 - 20p) = 3000 + 100p - 20p^2$$
$R'(p) = 100 - 40p = 0$ gives $p = 2.5$, and $R'' = -40 < 0$, so it is a
maximum. Charge \$12.50; 250 students come, for \$3,125 in revenue (up
from \$3,000).
\end{Answer}

\section{Helpful Table for Optimization Problems}
\begin{center}
\begin{tabular}{|p{4cm}|p{6cm}|p{4cm}|}
\hline
\textbf{Condition at a point $x = c$} & \textbf{What it tells you} & \textbf{What kind of point it could be} \\
\hline
$f'(c) \neq 0$ &
The graph has a non-horizontal tangent &
Not a maximum or minimum (unless $c$ is an endpoint) \\
\hline
$f'(c) = 0$ &
The graph has a horizontal tangent &
Possible maximum, minimum, or neither \\
\hline
$f'(c)$ does not exist &
The graph may have a corner, cusp, or vertical tangent &
Possible maximum or minimum; check the sign of $f'$ on each side \\
\hline
$f'(c) = 0$ and $f''(c) > 0$ &
Graph is concave up at $c$ &
Local minimum \\
\hline
$f'(c) = 0$ and $f''(c) < 0$ &
Graph is concave down at $c$ &
Local maximum \\
\hline
$f'(c) = 0$ and $f''(c) = 0$ &
Second derivative test fails &
Could be max, min, or neither \\
\hline
\end{tabular}

\section{Using Python to Visualize Your Optimization Problem}
The \pyfunction{sympy} library does algebra and calculus symbolically,
the way you do on paper. The script below takes the derivative, solves
$f'(x) = 0$, runs the second derivative test, and plots the result.

\begin{minted}{python}
import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

# 1) Define the variable
x = sp.symbols('x')

# 2) Define the objective function (STUDENTS EDIT THIS)
f = 20*x - x**2

# 3) Derivatives
f_prime = sp.diff(f, x)
f_double_prime = sp.diff(f_prime, x)

# 4) Solve f'(x) = 0
critical_point = sp.solve(f_prime, x)[0]

# 5) Classify using second derivative
second_derivative_value = f_double_prime.subs(x, critical_point)

if second_derivative_value > 0:
    classification = "minimum"
elif second_derivative_value < 0:
    classification = "maximum"
else:
    classification = "inconclusive"

print("f(x) =", f)
print("f'(x) =", f_prime)
print("f''(x) =", f_double_prime)
print("Critical point:", critical_point)
print("Classification:", classification)

# 6) Plot
f_num = sp.lambdify(x, f, "numpy")

X = np.linspace(0, 20, 400)
Y = f_num(X)

xc = float(critical_point)
yc = float(f_num(xc))

plt.plot(X, Y)
plt.scatter([xc], [yc])
plt.title("Optimization")
plt.xlabel("x")
plt.ylabel("f(x)")
plt.grid(True)

plt.annotate(
    classification,
    (xc, yc),
    xytext=(xc + 1, yc),
    arrowprops=dict(arrowstyle="->")
)

plt.show()
\end{minted}

\begin{Exercise}[label = optimization3]
The Python script above uses derivatives to locate and classify a
critical point of a function.

\begin{enumerate}
\item Run the script using the function
\[
f(x) = 20x - x^2.
\]
Record the critical point and whether it is classified as a maximum or
minimum.

\item Change the objective function in the script to
\[
f(x) = x^2 - 6x + 5.
\]
Run the script again. How does the classification change? Explain why
this happens using the second derivative test.

\item Change the objective function to
\[
f(x) = x^3.
\]
Run the script. What does the script report for the classification?
Explain why the second derivative test is inconclusive in this case.

\item Finally, choose your own quadratic function and predict whether
the critical point will be a maximum or minimum before running the
script. Check your prediction using both calculus and the graph.
\end{enumerate}
\end{Exercise}

\begin{Answer}[ref=optimization3]

\begin{enumerate}
\item For $f(x) = 20x - x^2$,

\[
f'(x) = 20 - 2x.
\]
Setting $f'(x)=0$ gives $20 - 2x = 0$, so $x = 10$.

\[
f''(x) = -2.
\]
Since $f''(10) < 0$, the function is concave down at the critical point,
so the critical point is a maximum.

\item For $f(x) = x^2 - 6x + 5$,

\[
f'(x) = 2x - 6.
\]
Setting $f'(x)=0$ gives $2x - 6 = 0$, so $x = 3$.

\[
f''(x) = 2.
\]
Since $f''(3) > 0$, the function is concave up at the critical point,
so the critical point is a minimum.

\item For $f(x) = x^3$,

\[
f'(x) = 3x^2.
\]
Setting $f'(x)=0$ gives $x = 0$.

\[
f''(x) = 6x.
\]
Since $f''(0) = 0$, the second derivative test gives no classification,
and the script reports the point as inconclusive. The graph shows that
$f$ increases on both sides of $x = 0$, so this critical point is
neither a maximum nor a minimum (Figure~\ref{fig:critical-point-types}).

\item For a quadratic function of the form $f(x) = ax^2 + bx + c$ with
$a \neq 0$, there is exactly one critical point at
\[
x = -\frac{b}{2a}.
\]
Also,
\[
f''(x) = 2a.
\]
If $a>0$, then $f''(x)>0$ and the critical point is a minimum.
If $a<0$, then $f''(x)<0$ and the critical point is a maximum.
\end{enumerate}

\end{Answer}
