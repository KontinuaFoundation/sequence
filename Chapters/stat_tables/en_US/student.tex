\chapter{Statistical Tables}

This chapter collects the three tables printed on the AP Statistics formula sheet: standard normal probabilities, $t$ critical values, and chi-square critical values. The layouts match the exam versions, so practice with these tables carries over directly to test day.  

\section{The Standard Normal Table}

Table~\ref{tab:z-negative} and Table~\ref{tab:z-positive} give the \newterm{cumulative probability}\index{cumulative probability} $P(Z \le z)$, the area under the standard normal curve to the left of $z$. Each row gives $z$ to one decimal place, and each column adds the second decimal place. To find $P(Z \le 1.37)$, go to row $1.3$ and column $.07$; the entry is $0.9147$.

Three rules cover every question this table answers:

\begin{itemize}
    \item Area to the left of $z$: read the table directly.
    \item Area to the right of $z$: subtract the table value from 1.
    \item Area between $z_1$ and $z_2$: subtract the smaller table value from the larger one.
\end{itemize}

To work backward from an area to a $z$-score, find the entry closest to the area in the body of the table, then read its row and column.

\begin{Exercise}[title={Areas under the standard normal curve}, label={ex:ztable-areas}]
Use the standard normal table to find each probability.
\begin{enumerate}
    \item[(a)] $P(Z \le 1.37)$
    \item[(b)] $P(Z > -0.84)$
    \item[(c)] $P(-1.25 < Z < 0.60)$
\end{enumerate}
\end{Exercise}

\begin{Answer}[ref={ex:ztable-areas}]
\begin{enumerate}
    \item[(a)] Row $1.3$, column $.07$: $0.9147$.
    \item[(b)] The table gives $P(Z \le -0.84) = 0.2005$, so $P(Z > -0.84) = 1 - 0.2005 = 0.7995$.
    \item[(c)] $P(Z \le 0.60) - P(Z \le -1.25) = 0.7257 - 0.1056 = 0.6201$.
\end{enumerate}
\end{Answer}

The closest entry to $0.90$ in the body of the table is $0.8997$, at row $1.2$ and column $.08$. So $z \approx 1.28$.
\end{Answer}

\section{The \texorpdfstring{$t$}{t} Table}

Table~\ref{tab:t-critical} gives the critical value $t^*$ that has upper-tail probability $p$ for a $t$ distribution with $df$ degrees of freedom. The table is read two ways.

\begin{itemize}
    \item For a confidence interval, use the confidence level $C$ along the bottom row. A 95 percent interval with $df = 24$ uses the column above $95\%$, giving $t^* = 2.064$.
    \item For a significance test, locate the test statistic between two entries in its $df$ row. The tail probabilities at the top of those two columns bound the one-sided $P$-value. Double both bounds for a two-sided test.
\end{itemize}

When the exact $df$ is missing from the table, use the next smaller $df$ that appears. The smaller $df$ gives a slightly larger $t^*$, so the resulting interval is a little wider and the conclusion stays conservative. The last row, $df = \infty$, contains the standard normal critical values $z^*$.

\begin{Exercise}[title={Critical values for confidence intervals}, label={ex:ttable-ci}]
Find $t^*$ for each interval.
\begin{enumerate}
    \item[(a)] A 95 percent confidence interval with $df = 24$.
    \item[(b)] A 99 percent confidence interval with $df = 45$.
\end{enumerate}
\end{Exercise}

\begin{Answer}[ref={ex:ttable-ci}]
\begin{enumerate}
    \item[(a)] Row $24$, column $C = 95\%$: $t^* = 2.064$.
    \item[(b)] The table has no row for $df = 45$, so use $df = 40$. Column $C = 99\%$ gives $t^* = 2.704$. The exact value for $df = 45$ is $2.690$, slightly smaller, which confirms that rounding $df$ down widens the interval.
\end{enumerate}
\end{Answer}

\begin{Exercise}[title={Bounding a \texorpdfstring{$P$}{P}-value}, label={ex:ttable-pvalue}]
A one-sided test with $df = 15$ produces $t = 2.30$. Use the $t$ table to find bounds on the $P$-value.
\end{Exercise}

\begin{Answer}[ref={ex:ttable-pvalue}]
In row $15$, $t = 2.30$ falls between $2.249$ (tail probability $0.02$) and $2.602$ (tail probability $0.01$). So $0.01 < P < 0.02$. Technology gives $P = 0.0181$, inside these bounds.
\end{Answer}

\begin{Exercise}[title={Reading the chi-square table}, label={ex:chitable}]
\begin{enumerate}
    \item[(a)] Find the critical value for a chi-square test at $\alpha = 0.05$ with $df = 12$.
    \item[(b)] A goodness-of-fit test with $df = 4$ produces $\chi^2 = 9.80$. Find bounds on the $P$-value.
\end{enumerate}
\end{Exercise}

\begin{Answer}[ref={ex:chitable}]
\begin{enumerate}
    \item[(a)] Row $12$, column $.05$: $21.026$.
    \item[(b)] In row $4$, $9.80$ falls between $9.488$ (tail probability $0.05$) and $11.143$ (tail probability $0.025$). So $0.025 < P < 0.05$. Technology gives $P = 0.0439$.
\end{enumerate}
\end{Answer}
