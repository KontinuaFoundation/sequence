\chapter{Numerical Double Integration}

In the Multivariate Distributions chapter, we gave an example of the \index{multivariate normal distribution}multivariate normal distribution: the mass and shell diameter of a population of snails.

Starting with a table of measurements, we estimated that the mean vector $\mu$ was $\begin{bmatrix}4.36 \text{g} & 2.35 \text{cm}\end{bmatrix}$.

We then computed the covariance matrix:

\begin{equation*}
\mathbf{\Sigma} = \begin{bmatrix}
1.33 &  0.443 \\
0.443 & 0.416 \\
\end{bmatrix}
\end{equation*}

Plotting the data points, the mean, and the equal-density contours looked like this:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.55\textwidth]{contour.png}
    \caption{Equal density contours plotted with the snail data.}
    \label{fig:contour}
\end{figure}

We have a great formula for computing the probability density for any mass/diameter combination:

\begin{equation*}
p(\mathbf{x}) = \frac{1}{\sqrt{(2\pi)^d|\mathbf{\Sigma}|}}\exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol\mu)^T\mathbf{\Sigma}^{-1}(\mathbf{x}-\boldsymbol\mu)\right)
\end{equation*}

Can you answer the following question? "If I pick a random snail off the floor of the ocean, what is the probability that its mass is between 3 and 4 grams
and its diameter is between 1.5 and 2.0 centimeters?"

If we think of the probability density as a surface, this question is really "What is the volume under the surface in the rectangular patch $3 \leq x_1 \leq 4$ and $1.5 \leq x_2 \leq 2.0$?"  Which you should recognize as a \index{double integral}double integration problem:

\begin{equation*}
P = \int_{1.5}^{2.0} \int_{3}^4 \frac{1}{\sqrt{(2\pi)^d|\mathbf{\Sigma}|}}\exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol\mu)^T\mathbf{\Sigma}^{-1}(\mathbf{x}-\boldsymbol\mu)\right) dx_1 dx_2
\end{equation*}

Sadly, the multivariate normal density has no elementary antiderivative, so we cannot write this integral in closed form.

Instead, we use \index{Riemann sum}Riemann sums to find an approximate solution.  This is known as \index{numerical integration}\newterm{numerical integration}.

(After spending so much time learning the techniques for integration, it may be disappointing to hear this:
For a lot of real-world problems, there is no way to find an antiderivative, so we end up doing numerical integration much more often than most people realize.)

For the diagram, we will just break each range into three, but you will get a more accurate estimate as the intervals get smaller.

\section{Numerical Integration in Python}\index{numerical integration!python}

Here is the code. It uses a midpoint Riemann sum, so each small square is evaluated at its center:

\begin{minted}{python}
import numpy as np
from scipy.stats import multivariate_normal

# pip3 install scipy
weight_lower_limit = 3.0
weight_upper_limit = 4.0
weight_slices = 100

diameter_lower_limit = 1.5
diameter_upper_limit = 2.0
diameter_slices = 100

# What is the average weight and diameter?
mean_vector = np.array([4.35559489,2.3526593 ])
print(f"Mean [weight, diameter] = {mean_vector}")

# Do heavier snails tend to have bigger shells?
covariance_matrix = np.array([[1.33099714,0.44309754],
 [0.44309754,0.41603925]])
print(f"Covariance = \n{covariance_matrix}")

# Create a multivariate normal distribution
rv = multivariate_normal(mean_vector, covariance_matrix)

delta_weight = (weight_upper_limit - weight_lower_limit) / weight_slices
delta_diameter = (diameter_upper_limit - diameter_lower_limit) / diameter_slices

total = 0.0
# Step through each different weight
for i in range(weight_slices):
    # What is the weight in the middle of this slice?
    current_weight = weight_lower_limit + (i + 0.5) * delta_weight

    for j in range(diameter_slices):
        # What is the diameter in the middle of this slice?
        current_diameter = diameter_lower_limit + (j + 0.5) * delta_diameter

        # What is the probability density there?
        prob_density = rv.pdf((current_weight, current_diameter))

        # What is the volume under that for this tiny square
        total += prob_density * delta_weight * delta_diameter

print(
    f"\nThe probability that the weight is between {weight_lower_limit} and {weight_upper_limit}"
)
print(
    f"and that the diameter is between {diameter_lower_limit} and {diameter_upper_limit}"
)
print(f"is about {total * 100.0:.4f}%")
\end{minted}

This should get you the following output:

\begin{minted}{python}
> python3 num_integration.py
Mean [weight, diameter] = [4.35559489 2.3526593 ]
Covariance =
[[1.33099714 0.44309754]
 [0.44309754 0.41603925]]

The probability that the weight is between 3.0 and 4.0
and that the diameter is between 1.5 and 2.0
is about 7.8316%
\end{minted}

How good is this estimate? Using only $10 \times 10 = 100$ squares instead of
$100 \times 100$ gives $7.8364\%$, already within $0.005$ percentage points.
SciPy can also compute this particular probability directly from the
cumulative distribution function, and it gets $7.8316\%$, matching our
10,000-square estimate to four decimal places. The midpoint rule converges
quickly for smooth functions like this one.

\begin{Exercise}[label = numint1]
Estimate $\iint_R (x^2 + y^2)\,dA$ over $R = [0, 1] \times [0, 1]$ by hand, using a
midpoint Riemann sum with a $2 \times 2$ grid. Compare your answer with the exact
value.
\end{Exercise}

\begin{Answer}[ref = numint1]
The midpoints are $(0.25, 0.25)$, $(0.25, 0.75)$, $(0.75, 0.25)$, and $(0.75, 0.75)$,
where $f$ equals $0.125$, $0.625$, $0.625$, and $1.125$. Each square has area
$0.25$, so the estimate is $0.25(0.125 + 0.625 + 0.625 + 1.125) = 0.625$. The exact
value is $\int_0^1\int_0^1 (x^2 + y^2)\,dy\,dx = \frac{1}{3} + \frac{1}{3} = \frac{2}{3}
\approx 0.667$. Even four squares get within about 6\%.
\end{Answer}
