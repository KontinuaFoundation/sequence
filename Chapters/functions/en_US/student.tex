\chapter{Functions and Their Graphs}

Think of a vending machine. You press B4, and out comes the same bag of
chips every time. A \index{function}function works the same way: you put in
a number, the function follows its rule, and out comes exactly one answer.

Just as we use $x$ to stand for a number, we often use $f$ to stand for a
function. We write $f(x)$ and say ``f of x.'' The name does not have to be
$f$. Any letter or word will do, even $\mathrm{zebra}(x)$.

For example, let the function $f$ be defined like this:

\begin{equation*}
  f(x) = -5x^2 + 12x + 2
\end{equation*}

What is $f(3)$?

Run 3 through the machine: $-5(3^2) + 12(3) + 2 = -45 + 36 + 2 = -7$. So
$f(3) = -7$.

Some functions refuse certain inputs. For example:

\begin{equation*}
  f(x) = \frac{1}{x}
\end{equation*}

This works for any $x$ except 0, because you cannot divide by 0. The set of
inputs a function accepts is its \newterm{domain}\index{domain}. The set of
outputs it produces is its \newterm{range}\index{range}.

A function gives exactly one output for each input. Two inputs may share an
output (both $2$ and $-2$ square to $4$), but one input can never give two
outputs. A rule that does give two outputs for some input is called a
\newterm{relation}, not a function. The
\hyperref[sec:vertical]{vertical line test} spots these.

\begin{Exercise}[title={Domain of a function}, label=function_domain]


  \vspace{2cm}

  \begin{center}
    \vbox to 2cm{\vfil
        Let the function $f$ be given by $f(x) = \sqrt{x - 3}$.  What is its domain?
        \vfil}
  \end{center}
\end{Exercise}
\begin{Answer}[ref=function_domain]
  You can only take the square root of nonnegative numbers, so the
  function is only defined when $x - 3 \geq 0$.  Thus, the domain is
  all real numbers greater than or equal to 3.
\end{Answer}

\textbf{Worked example: evaluating a function.}
Let $f(x) = x^2 - 1$. Then $f(3) = 9 - 1 = 8$, and $f(-2) = 4 - 1 = 3$.

\section{Graphs of Functions}

If you have a function, $f$, its graph is the set of pairs $(x, y)$
such that $y = f(x)$.  We usually draw a picture of this set, called a \textit{graph}.
The graph not only includes the picture, but also the values of x and y used to create it.

\section{Graphing Calculators}

The fastest way to see a function is a graphing calculator.
\index{Desmos}Desmos is a free one that runs in your browser.

In a web browser, go to Desmos: \url{https://www.desmos.com/calculator}

In the field on the left, enter the function $y = x^2 - x - 6$. (For
the exponent, just prefix it with a caret symbol: ``x\^{}2''.)

\includegraphics[width=0.85\textwidth]{Desmos.png}

\textbf{Computing in Python}

Python can draw the same graph. The listing below uses two libraries:
NumPy, which builds lists of numbers called \newterm{arrays}\index{array},
and Matplotlib, which plots them.

\begin{minted}{python}
import numpy as np
import matplotlib.pyplot as plt

def f(x):
    return x**2 - x - 6

x = np.linspace(-5, 6, 200)
y = f(x)

plt.plot(x, y)
plt.axhline(0, color="black", linewidth=0.8)
plt.axvline(0, color="black", linewidth=0.8)
plt.grid(True)
plt.xlabel("x")
plt.ylabel("y")
plt.title("y = x^2 - x - 6")
plt.show()
\end{minted}

The \mintinline{python}{def} line packages the rule $x^2 - x - 6$ into a
Python function named \mintinline{python}{f}. Calling
\mintinline{python}{f(3)} runs 3 through the machine, the same way $f(3)$
does on paper. The call \mintinline{python}{np.linspace(-5, 6, 200)} creates
200 evenly spaced $x$ values from $-5$ to $6$, and passing that whole array to
\mintinline{python}{f} returns the 200 matching $y$ values at once.
Matplotlib then draws a point at each $(x, y)$ pair and joins neighboring
points with short line segments. With 200 points, each segment is short enough
that the curve looks smooth. The calls \mintinline{python}{axhline} and
\mintinline{python}{axvline} draw the $x$-axis and $y$-axis, and
\mintinline{python}{plt.show()} opens the plot window.

\begin{Exercise}[title={Reading values from f}, label={ex:functions-python-1}]
  Add this line after the plot code:
  \begin{minted}{python}
print(f(0), f(3), f(-2))
  \end{minted}
  What does it print? What do the three outputs tell you about the graph?
\end{Exercise}
\begin{Answer}[ref={ex:functions-python-1}]
  It prints \mintinline{python}{-6 0 0}. The first value says the graph
  crosses the $y$-axis at $(0, -6)$. The two zeros say $x = 3$ and $x = -2$
  are the $x$-intercepts, the points where the parabola crosses the
  $x$-axis. Both match the Desmos graph.
\end{Answer}

Desmos handles the asymptote of $\frac{1}{x}$ on its own. Matplotlib joins
every pair of neighboring points, so the two branches of $\frac{1}{x}$ need
separate arrays, one on each side of $x = 0$:

\begin{minted}{python}
x_left = np.linspace(-6, -0.15, 100)
x_right = np.linspace(0.15, 6, 100)

plt.plot(x_left, 1 / x_left, color="C0")
plt.plot(x_right, 1 / x_right, color="C0")
plt.axhline(0, color="black", linewidth=0.8)
plt.axvline(0, color="black", linewidth=0.8)
plt.ylim(-7, 7)
plt.grid(True)
plt.title("y = 1/x")
plt.show()
\end{minted}

Both calls use \mintinline{python}{color="C0"}, Matplotlib's default blue,
so the two branches read as one function. The call
\mintinline{python}{plt.ylim(-7, 7)} fixes the visible $y$ range to match
Figure~\ref{fig:graphed2}.

\begin{Exercise}[title={The phantom line}, label={ex:functions-python-2}]
  A student plots $\frac{1}{x}$ with a single array:
  \begin{minted}{python}

plt.show()
  \end{minted}

\end{Exercise}
\begin{Answer}[ref={ex:functions-python-2}]
  This array skips 0. The two entries closest to it are $x \approx -0.0606$
  and $x \approx 0.0606$, with $y \approx -16.5$ and $y \approx 16.5$.
  Matplotlib connects neighbors, so it draws a nearly vertical segment from
  $(-0.0606, -16.5)$ up to $(0.0606, 16.5)$. That segment belongs to neither
  branch of the graph. Plotting each side of the asymptote separately
  removes it. (With 101 points instead of 100, the array contains 0 exactly;
  NumPy then warns \mintinline{python}{divide by zero} and stores
  \mintinline{python}{inf} for that entry.)
\end{Answer}

\section{Even and Odd Functions}


\subsection{Even Functions}

An \index{even function}even function is symmetric about the $y$-axis:
fold the graph along the $y$-axis, and the two sides match perfectly. In
other words, $x$ and $-x$ always give the same output.


\begin{mdframed}[style=important, frametitle={Even Functions}]

  A function \( f(x) \) is even if
  \[
    f(-x) = f(x)
  \]
  for all \( x \) in its domain.
\end{mdframed}
Examples:
\begin{itemize}
  \item \( f(x) = x^2 \)
  \item \( f(x) = \cos(x) \)
  \item any \( f(x) = x^n \) where \( n \) is an even number
  \item \( f(x) = |x| \)
\end{itemize}

\subsection{Odd Functions}

An \index{odd function}odd function is symmetric about the origin: spin
the graph $180^\circ$ around the origin, and it lands on itself. In other
words, if $k$ goes in and $n$ comes out, then $-k$ goes in and $-n$ comes
out.


\begin{mdframed}[style=important, frametitle={Odd Functions}]

  A function \( f(x) \) is odd if
  \[
    f(-x) = -f(x)
  \]
  for all \( x \) in its domain.

  Equivalently,

  \[ f(x) + f(-x) = 0 \]
  for all \( x \) in its domain.
\end{mdframed}

\begin{itemize}

  \item \( f(x) = x^3 \)
  \item \( f(x) = \sin(x) \)
  \item \( f(x) = \tan(x) \)
  \item any \( f(x) = x^n \) where \( n \) is an odd number
\end{itemize}

\subsection{Neither Even Nor Odd}
Some functions are neither even nor odd.

For example, \( f(x) = x^3 + 1 \) satisfies neither condition: $f(1) = 2$,
but $f(-1) = 0$, which is neither $2$ nor $-2$.


\textbf{Computing in Python}

A plot can test for symmetry. Draw $h(x)$, $h(-x)$, and $-h(-x)$ on one set
of axes. When the $h(-x)$ curve lies on top of $h(x)$, the function is even.
A match between $-h(-x)$ and $h(x)$ means the function is odd.

\begin{minted}{python}
import numpy as np
import matplotlib.pyplot as plt

def h(x):
    return x**3 + 1

x = np.linspace(-2, 2, 200)

plt.plot(x, h(x), label="h(x)")
plt.plot(x, h(-x), linestyle="--", label="h(-x)")
plt.plot(x, -h(-x), linestyle=":", label="-h(-x)")
plt.grid(True)
plt.legend()
plt.show()
\end{minted}

Writing \mintinline{python}{h(-x)} negates every entry of the array before
it reaches \mintinline{python}{h}, and the extra minus sign in
\mintinline{python}{-h(-x)} negates every output afterward. For
$h(x) = x^3 + 1$, the dashed and dotted curves both separate from the solid
one, so $x^3 + 1$ is neither even nor odd.

The function \mintinline{python}{np.allclose(a, b)} turns the visual check
into a yes or no answer. It returns \mintinline{python}{True} when two arrays
agree at every entry, allowing for tiny rounding errors:

\begin{minted}{python}
print(np.allclose(h(-x), h(x)))   # even test
print(np.allclose(-h(-x), h(x)))  # odd test
\end{minted}

Both lines print \mintinline{python}{False} for $h(x) = x^3 + 1$.

\begin{Exercise}[title={One input is enough}, label={ex:functions-python-4}]
  Predict the output, then run it:
  \begin{minted}{python}
print(h(1), h(-1), -h(-1))
  \end{minted}
  How do these three numbers show that $h$ is neither even nor odd?
\end{Exercise}
\begin{Answer}[ref={ex:functions-python-4}]
  It prints \mintinline{python}{2 0 0}. An even function needs
  $h(-1) = h(1)$, but $0 \neq 2$. Oddness requires $-h(-1) = h(1)$, which
  fails for the same reason. A single input that breaks a definition is enough
  to rule it out.
\end{Answer}

\begin{Exercise}[title={Swap the function}, label={ex:functions-python-5}]
  Change the body of \mintinline{python}{h} to
  \mintinline{python}{return np.abs(x)} and run the plot and both
  \mintinline{python}{allclose} tests. Then change it to
  \mintinline{python}{return x**3} and run everything again. For each
  version, which curve lands on top of the solid one, and what do the tests
  print?
\end{Exercise}
\begin{Answer}[ref={ex:functions-python-5}]
  For \mintinline{python}{np.abs(x)}, the dashed $h(-x)$ curve lies exactly
  on the solid curve, and the tests print \mintinline{python}{True} then
  \mintinline{python}{False}: $|x|$ is even. With
  \mintinline{python}{x**3}, the dotted $-h(-x)$ curve lies on the solid
  curve, and the tests print \mintinline{python}{False} then
  \mintinline{python}{True}: $x^3$ is odd.
\end{Answer}

\section{Piecewise Functions}
Your phone plan might charge one rate for the first few gigabytes and
another after that. Rules like this are \newterm{piecewise
functions}\index{piecewise functions}: they use different formulas on
different parts of the domain. You pick the formula based on where the input
falls. Here is a simple example:
\begin{equation*}
  f(x) = \begin{cases}
    \frac{1}{x} & x < 0   \\
    x^2         & x \ge 0
  \end{cases}
\end{equation*}

When $x<0$, we use $\frac{1}{x}$; when $x\ge0$, we use $x^2$. The input
$x=0$ would break $\frac{1}{x}$, but it falls in the $x^2$ case, so $f$ is
defined for every real number. Here is a table of values:

\begin{tabular}{|c|c|c|c|c|c|c|}\hline
  $x$    & $-2$            & $-1$ & $0$ & $0.1$  & $1$ & $2$ \\
  \hline
  $f(x)$ & $-\tfrac{1}{2}$ & $-1$ & $0$ & $0.01$ & $1$ & $4$ \\
  \hline
\end{tabular}

And here is the graph:
\begin{figure}[H]
  \centering
  \begin{tikzpicture}
    \begin{axis}[
        xmin=-2.5,xmax=2.5,
        ymin=-2.5,ymax=4.5,
        axis x line=middle,
        axis y line=middle,
        axis line style=<->,
        xlabel={$x$},
        ylabel={$y$},
        samples=200,
      ]
      \addplot[thick,no marks,sdkblue,domain=-2:-0.2]{1/x};
      \addplot[thick,no marks,sdkblue,domain=0:2]{x^2};
      \addplot[thick,only marks,mark=*,sdkblue] coordinates {(0,0)};
    \end{axis}
  \end{tikzpicture}


  \caption{The piecewise function $f(x)$ graphed.}
  \label{fig:pw1}
\end{figure}
Notice the \emph{closed circle} at $(0,0)$. A closed circle marks a point
that is on the graph. An \emph{open circle} marks a point that is not. Here
is a function that needs both:
\begin{equation*}
  g(x) = \begin{cases}
    x^2 + 1 & x < 0   \\
    x^2     & x \ge 0
  \end{cases}
\end{equation*}
Its graph has an open circle at $(0,1)$, where the left piece stops just
short, and a closed circle at $(0,0)$, where the right piece starts.

\begin{Answer}[ref={ex:abs_val_pw}]
  For $x \ge 0$, $|x| = x$. For $x < 0$, $|x| = -x$, which flips the

    \begin{cases}
      x  & x \ge 0 \\
      -x & x < 0
    \end{cases}$$
\end{Answer}

\subsection{Floor and Ceiling Functions}
Two famous piecewise functions are the \newterm{floor
function}\index{floor function} and the \newterm{ceiling
function}\index{ceiling function}. The floor of any real number $x$ is
\begin{equation*}
  \lfloor x \rfloor \text{ or } \mathrm{floor}(x)=
  \begin{cases}
    n & \text{if } n \le x < n+1,\quad n \in \mathbb{Z}
  \end{cases}
  \label{eq:floor}
\end{equation*}

In words: the floor is the greatest integer less than or equal to $x$. For
example, $\lfloor 0.7 \rfloor = 0$. Your age works this way: if you are
15.8 years old, you say you are 15.

The ceiling function rounds the other way:
\begin{equation*}
  \lceil x \rceil \text{ or } \mathrm{ceil}(x)=
  \begin{cases}
    n & \text{if } n-1 < x \le n,\quad n \in \mathbb{Z}
  \end{cases}
  \label{eq:ceil}
\end{equation*}
The ceiling is the smallest integer greater than or equal to $x$. For
example, $\lceil 8.00001 \rceil = 9$. Parking garages work this way: stay
2 hours and 1 minute, and you pay for 3 hours. For an integer such as 7,
$\lfloor 7 \rfloor$ and $\lceil 7 \rceil$ are both 7.

\begin{Exercise}[title={More TVs is Better}, label={ex:tvs}]

A store sells televisions with pricing that depends on how many units a customer buys:
\begin{itemize}
  \item For the first 5 TVs, the cost per TV is $\mathdollar400$
  \item For the next 10 TVs, the cost per TV is $\mathdollar350$
  \item Any additional TVs cost $\mathdollar 300$
\end{itemize}

A hotel is buying TVs for each hotel room.
\begin{enumerate}
  \item Construct a piecewise function $C(x)$ for the cost of TVs. Assume TVs must be a discrete integer (you cannot buy 8.5 TVs).
  \item Find the cost of 12 TVs using your function.
  \item How many TVs must the hotel buy for the average cost per TV to drop
        below $\mathdollar360$?
\end{enumerate}
\end{Exercise}
\begin{Answer}[ref={ex:tvs}]

\begin{enumerate}
  \item $$C(x) =
\begin{cases}
400x & 0 < x \le 5 \\
2000 + 350(x - 5) & 5 < x \le 15 \\
5500 + 300(x - 15) & x > 15
\end{cases}$$
\item $C(12) = 2000 + 350(12 - 5) = \mathdollar4450$
\item We need $\frac{C(x)}{x} < 360$. In the second case,
$\frac{C(x)}{x} = 350 + \frac{250}{x}$, which stays above 360 for every
$x \le 15$. So we need the third case:
$$C(x) = 5500 + 300(x - 15) = 5500 + 300x - 4500 = 1000 + 300x$$ 
Now, 
$$\frac{1000 + 300x}{x} < 360$$
\begin{align*}
  300 + \frac{1000}{x} &< 360\\
  \frac{1000}{x} &< 60 \\ 
  1000 &< 60x\\
  x &> \frac{1000}{60} \approx 16.67 \rightarrow 17
\end{align*}
The hotel must buy at least 17 TVs. Check: $C(17) = \mathdollar6100$, and
$\frac{6100}{17} \approx \mathdollar358.82$.
\end{enumerate}

\end{Answer}

\subsection{Invalid Piecewise Functions}
When you write a piecewise function, make sure the cases do not overlap
with different answers. Here is a broken one:
\begin{equation*}
  f(x) = \begin{cases}
    10.2 & x = 4   \\
    x^2  & x \ge 0
  \end{cases}
\end{equation*}

At $x=4$, the first case says $f(4) = 10.2$ and the second says
$f(4) = 16$. One input, two outputs: not a function. The fix is to exclude
4 from the second case:
\begin{equation*}
  f(x) =
  \begin{cases}
    10.2 & x = 4              \\
    x^2  & x \ge 0,\; x \ne 4
  \end{cases}
\end{equation*}
Now $f(4) = 10.2$, with no argument.

\textbf{Computing in Python}

Matplotlib draws a piecewise graph one piece at a time. Here is $g(x)$ from
earlier in this section, with its open and closed circles:

\begin{minted}{python}
import math
import numpy as np
import matplotlib.pyplot as plt

x_left = np.linspace(-2, 0, 100)
x_right = np.linspace(0, 2, 100)

plt.plot(x_left, x_left**2 + 1, color="C0")
plt.plot(x_right, x_right**2, color="C0")
plt.plot(0, 0, "o", color="C0")                           # closed circle
plt.plot(0, 1, "o", color="C0", markerfacecolor="white")  # open circle
plt.grid(True)
plt.title("piecewise g(x)")
plt.show()
\end{minted}

Each piece gets its own array covering only its part of the domain. A single
array across the whole domain would join the two pieces with a vertical
segment at $x = 0$, the same phantom line that appears with $\frac{1}{x}$.
The format string \mintinline{python}{"o"} draws one round marker, and
\mintinline{python}{markerfacecolor="white"} hollows it out into an open
circle.

Plotting shows the shape. Evaluating the function at a particular input
takes \mintinline{python}{if} and \mintinline{python}{elif}, with one
condition for each row of the cases. This is the function from
Exercise~\ref{ex:pw_3_case}:

\begin{minted}{python}
def p(x):
    if -5 <= x < -1:
        return x + 2
    elif -1 <= x <= 2:
        return x**2
    elif 2 < x <= 5:
        return 3 - x
    return None

for x in range(-5, 6):
    print(x, p(x))
\end{minted}

Python accepts chained comparisons such as \mintinline{python}{-5 <= x < -1},
written exactly in math notation. It checks the conditions from top to bottom
and returns from the first one that is true. An input outside every case,
such as \mintinline{python}{p(6)}, reaches the last line and returns
\mintinline{python}{None}, Python's value for ``nothing.'' That matches the
function being undefined there. The call \mintinline{python}{range(-5, 6)}
produces the integers from $-5$ up to $5$; the stop value 6 is left out.

\begin{Exercise}[title={Checking the table}, label={ex:functions-python-6}]
  Run the loop above. Compare its output with the table in the answer to
  Exercise~\ref{ex:pw_3_case}. Which case does Python use at $x = -1$ and at
  $x = 2$?
\end{Exercise}
\begin{Answer}[ref={ex:functions-python-6}]
  The outputs for $x = -5, -4, \ldots, 5$ are
  $-3, -2, -1, 0, 1, 0, 1, 4, 0, -1, -2$, matching the table. At $x = -1$
  the first condition fails ($-1 < -1$ is false), so Python uses $x^2$ and
  returns 1. At $x = 2$ the second condition includes 2, so Python returns
  $2^2 = 4$. Both are the closed circles on the graph.
\end{Answer}

\begin{Exercise}[title={The case that never runs}, label={ex:functions-python-7}]
  A student codes the revised function from the end of this section:
  \begin{minted}{python}
def q(x):
    if x >= 0:
        return x**2
    elif x == 4:
        return 10.2
  \end{minted}
  The call \mintinline{python}{q(4)} returns \mintinline{python}{16}
  instead of \mintinline{python}{10.2}. Find the error and fix it.
\end{Exercise}
\begin{Answer}[ref={ex:functions-python-7}]
  The input 4 satisfies \mintinline{python}{x >= 0}, so Python returns
  $4^2 = 16$ and never reaches the \mintinline{python}{elif}. Python does
  not flag overlapping cases; it takes the first match. Putting the special
  case first fixes it:
  \begin{minted}{python}
def q(x):
    if x == 4:
        return 10.2
    elif x >= 0:
        return x**2
  \end{minted}
  Now \mintinline{python}{q(4)} returns \mintinline{python}{10.2} and
  \mintinline{python}{q(3)} returns \mintinline{python}{9}. Ordering the
  checks this way does the same job as the condition $x \ge 0,\; x \ne 4$ in
  the revised definition.
\end{Answer}

\begin{Exercise}[title={Floor and ceiling in Python}, label={ex:functions-python-8}]
  Python's \mintinline{python}{math} module provides
  \mintinline{python}{math.floor} and \mintinline{python}{math.ceil}.
  Predict the output:
  \begin{minted}{python}
print(math.floor(-2.5), math.ceil(-2.5), math.ceil(8.00001), math.floor(7))
  \end{minted}
\end{Exercise}
\begin{Answer}[ref={ex:functions-python-8}]
  It prints \mintinline{python}{-3 -2 9 7}. Flooring $-2.5$ moves down to
  $-3$, the greatest integer less than or equal to $-2.5$; rounding toward
  zero would give $-2$, which is wrong here. Its ceiling is $-2$. An input of
  $8.00001$ rises to 9, and an integer such as 7 comes back unchanged.
\end{Answer}


\section{Summary}
A function is a machine that turns each input into exactly one output. Its
domain is the set of inputs it accepts; its range is the set of outputs it
produces.

The graph of $f$ is the set of points $(x, f(x))$. A set of points is the
graph of a function only if it passes the vertical line test.

Even functions are mirror images across the $y$-axis ($f(-x) = f(x)$). Odd
functions survive a half turn about the origin ($f(-x) = -f(x)$). Piecewise
functions use different formulas on different parts of the domain; floor
and ceiling are two famous examples.

\begin{Exercise}[title={Solve for x}, label=fn1]
Let $g(x) = 2x + 5$. Find $g(-1)$, and find the value of $x$ for which $g(x) = 11$.
\end{Exercise}
\begin{Answer}[ref=fn1]
$g(-1) = 2(-1) + 5 = 3$. Solving $2x + 5 = 11$ gives $x = 3$.
\end{Answer}
