\chapter{Linear Regression and Gradient Descent}

\section{Why Iterate?}\index{gradient descent}
The least squares solution is a formula, $\mathbf{b} = (X^TX)^{-1}X^T\mathbf{y}$. For many features, forming and solving
$X^TX$ is expensive. \newterm{Gradient descent} reaches nearly the same answer by repeated small steps, which can scale to
very large problems.

\section{The Cost Function}
The cost for linear regression is the mean squared error:
$$J(\boldsymbol{\theta}) = \frac{1}{n}\sum_{i=1}^n (\mathbf{x}_i^T\boldsymbol{\theta} - y_i)^2$$
In matrix form, its gradient is
$$\nabla J(\boldsymbol{\theta}) = \frac{2}{n} X^T(X\boldsymbol{\theta} - \mathbf{y})$$

\section{The Update Rule}
Start with a guess $\boldsymbol{\theta}_0$, usually zero. At each step, move against the gradient, scaled by the \newterm{learning rate} $\alpha$:
$$\boldsymbol{\theta} := \boldsymbol{\theta} - \alpha \nabla J(\boldsymbol{\theta})$$
If $\alpha$ is too large, the steps overshoot and the cost can grow. If $\alpha$ is too small, progress is slow.

\section{A Worked Step}
Use the quiz data from the simple linear regression chapter: $x = 1, \ldots, 5$ and $y = 2.1, 3.9, 6.2, 7.8, 10.1$.
With $X$ having a column of ones and the $x$ values, and $\boldsymbol{\theta}_0 = (0, 0)$, we have
$X\boldsymbol{\theta}_0 - \mathbf{y} = -\mathbf{y}$. Then $X^T(-\mathbf{y}) = (-30.1, -110.2)$, so with $n = 5$,
$$\nabla J(\boldsymbol{\theta}_0) = \frac{2}{5}(-30.1, -110.2) = (-12.04, -44.08)$$
With $\alpha = 0.01$,
$$\boldsymbol{\theta}_1 = (0, 0) - 0.01(-12.04, -44.08) = (0.1204, 0.4408)$$
The true solution is $(0.05, 1.99)$, so the steps move toward it.

\section{Standardizing First}
The gradient descent convergence depends on the scale of the features. If one feature is in thousands and another is in fractions,
the cost surface is stretched into a narrow valley, and steps along the valley are very slow. Standardize the features first, so
the cost surface is more round and gradient descent converges faster. The chapter on standardization gives the formula.

\begin{Exercise}[label=gd1, title=One more step]
Starting from $\boldsymbol{\theta}_1 = (0.1204, 0.4408)$, take one gradient step with $\alpha = 0.01$ on the quiz data.
Find $\boldsymbol{\theta}_2$, rounding to four decimal places.
\end{Exercise}
\begin{Answer}[ref=gd1]
The predictions are $X\boldsymbol{\theta}_1 = (0.5612, 1.0020, 1.4428, 1.8836, 2.3244)$. The residuals
$X\boldsymbol{\theta}_1 - \mathbf{y} = (-1.5388, -2.8980, -4.7572, -5.9164, -7.7756)$. Then
$X^T(X\boldsymbol{\theta}_1 - \mathbf{y}) = (-22.886, -84.150)$, so $\nabla J = \frac{2}{5}(-22.886, -84.150) = (-9.1544, -33.660)$ and
$\boldsymbol{\theta}_2 = (0.1204, 0.4408) - 0.01(-9.1544, -33.660) = (0.2119, 0.7774)$.
\end{Answer}

\begin{Exercise}[label=gd2, title=Learning rate]
What happens to gradient descent if $\alpha$ is made very large?
\end{Exercise}
\begin{Answer}[ref=gd2]
The steps overshoot the minimum. The parameters can oscillate or diverge, and the cost can increase instead of decrease.
\end{Answer}
