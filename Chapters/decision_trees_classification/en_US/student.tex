\chapter{Decision Trees for Classification}

\section{The Idea}\index{decision tree}
A \newterm{decision tree} predicts a class by asking a series of questions about the features. Each internal node tests one
feature against a threshold. Each leaf gives a predicted class. A good tree puts the points in each leaf into one class, or as
close to that as possible.

\section{Gini Impurity}\index{Gini impurity}
The \newterm{Gini impurity} of a node measures how mixed its classes are. If $p_i$ is the fraction of points in the node that belong
to class $i$, then
$$G = 1 - \sum_{i} p_i^2$$
A pure node has $G = 0$. A node with two equally common classes has $G = 0.5$.

\section{Choosing a Split}\index{decision tree!splitting}
At each node, the tree tries each feature and each threshold, and keeps the split with the lowest weighted impurity of the two
children. The weight of each child is its share of the points.

\subsection{A Worked Example}
A node holds 6 points of class A and 4 points of class B. Its impurity is
$$G = 1 - (0.6^2 + 0.4^2) = 1 - 0.52 = 0.48$$
Suppose a split sends 4 A and 1 B to the left child, and 2 A and 3 B to the right child. Each child has 5 points.
The left impurity is $1 - (0.8^2 + 0.2^2) = 0.32$, and the right is $1 - (0.4^2 + 0.6^2) = 0.48$. The weighted impurity is
$$\frac{5}{10}(0.32) + \frac{5}{10}(0.48) = 0.40$$
The split lowers the impurity from 0.48 to 0.40.

\section{Stopping and Overfitting}
Growing the tree until every leaf is pure can memorize the training data. Limit the depth of the tree, or require a minimum
number of points in each leaf, to keep it general. The validation set is used to choose these limits.

\begin{Exercise}[label=dt1, title=Compute impurity]
A node holds 3 points of class A and 1 point of class B. What is its Gini impurity?
\end{Exercise}
\begin{Answer}[ref=dt1]
$G = 1 - (0.75^2 + 0.25^2) = 1 - 0.625 = 0.375$.
\end{Answer}

\begin{Exercise}[label=dt2, title=Is the split better?]
A node with $G = 0.48$ is split into two children of equal size with $G = 0.2$ and $G = 0.3$. Is the split an improvement?
\end{Exercise}
\begin{Answer}[ref=dt2]
The weighted impurity is $0.5(0.2) + 0.5(0.3) = 0.25$, which is lower than 0.48. The split is an improvement.
\end{Answer}
