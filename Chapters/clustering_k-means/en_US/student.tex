\chapter{Clustering with k-Means}

\section{Unsupervised Learning}\index{k-means clustering}
In \newterm{unsupervised learning}, there are no labels. We look for structure in the inputs alone. \newterm{Clustering} groups
the points so that points in the same group are close to each other. The \newterm{$k$-means} algorithm does this for a chosen number of groups $k$. Think of splitting a class into project groups by interest, when you already know how many groups you want.

\section{The Algorithm}
Given points $x_1, \ldots, x_N$ and a number $k$, k-means seeks centroids $c_1, \ldots, c_k$ that minimize the total squared distance from
each point to its nearest centroid. It alternates two steps.
\begin{enumerate}
\item \textbf{Assign}: each point joins the cluster of its nearest centroid.
\item \textbf{Update}: each centroid moves to the mean of the points assigned to it.
\end{enumerate}
Repeat until the assignments stop changing. The result depends on the starting centroids, so the algorithm is often run several times.

\section{A Worked Example}
Four points on a line are $1, 2, 6, 8$, and $k = 2$. Start with centroids $c_1 = 1$ and $c_2 = 6$.
\begin{itemize}
\item Assign: the points $1$ and $2$ are nearer $c_1$, and the points $6$ and $8$ are nearer $c_2$.
\item Update: $c_1 = \frac{1 + 2}{2} = 1.5$ and $c_2 = \frac{6 + 8}{2} = 7$.
\end{itemize}
The next assignment is the same, so the algorithm stops with clusters $\{1, 2\}$ and $\{6, 8\}$.
The total squared distance is $0.5^2 + 0.5^2 + 1^2 + 1^2 = 2.5$.

\section{Choosing k}
The number $k$ is not learned by the algorithm. The \newterm{elbow method} plots the total squared distance against $k$. The total always falls as $k$ grows,
and the point where the decrease levels off is a common choice. Other methods, such as silhouette scores, compare how well separated the clusters are.

\begin{Exercise}[label=km1, title=One iteration]
Using the four points $1, 2, 6, 8$, start with the poorly placed centroids $c_1 = 1$ and $c_2 = 2$. Run k-means until it stops.
\end{Exercise}
\begin{Answer}[ref=km1]
Iteration 1: point $1$ joins $c_1$, and points $2$, $6$, and $8$ join $c_2$. The centroids become $c_1 = 1$ and
$c_2 = \frac{2 + 6 + 8}{3} \approx 5.33$.
Iteration 2: point $2$ is now nearer $c_1$ (distance 1 versus 3.33), so the clusters are $\{1, 2\}$ and $\{6, 8\}$, and the
centroids become $1.5$ and $7$. Iteration 3 changes nothing, so the algorithm stops. Even from a bad start,
it found the natural clusters here, though that does not always happen.
\end{Answer}

\begin{Exercise}[label=km2, title=Why run it again?]
Why is k-means usually run several times with different starting centroids?
\end{Exercise}
\begin{Answer}[ref=km2]
The algorithm converges to a local minimum of the total squared distance, and different starting centroids can lead to different final clusters.
\end{Answer}
